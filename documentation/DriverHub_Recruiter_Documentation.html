1. Assignment Scope & Technology Choices

Driver Hub is a specialized recruitment platform designed to connect commercial drivers with fleet operators and logistics companies. Both a Production Web Application and a Native Android Mobile Application have been engineered with a shared Supabase PostgreSQL cloud backend.

✓ Web App (React 18 + TS + Tailwind) ✓ Android App (Expo / React Native) Supabase Cloud PostgreSQL Real-time WebSocket Sync Role-Based Access Control (RBAC) AI Driver Support Assistant

2. Assignment Requirement Checklist & Feature Mapping

🚗 For Drivers / Candidates

  • ✓ Registration & Login: Role-specific signup with phone, category, and license details.
  • ✓ Create & Manage Profile: Dynamic bio, expected salary, availability, and badge type.
  • ✓ Experience & Skills: Heavy transport, trailer handling, GPS navigation tags.
  • ✓ Document Uploads: Driving license, badge certificate, and resume attachment.
  • ✓ Search & Filter Jobs: Filter by vehicle category (HMV, LMV, Bus), city, and salary.
  • ✓ Apply & Track Applications: 5-stage progress bar (Applied → Review → Shortlist → Trial → Hired).
  • ✓ Notifications: Real-time alerts for interview schedules and shortlists.

🏢 For Employers & Fleets

  • ✓ Employer Registration & Login: Company profile with GST/depot details.
  • ✓ Company Profile Management: Fleet size, operating corridors, and website.
  • ✓ Post Job Vacancies: Category, experience years, salary bracket, shift hours, required docs.
  • ✓ Application Pipeline: Candidate reviews with resume previews.
  • ✓ Search Driver Profiles: Search verified candidates by badge & location.
  • ✓ Shortlist & Contact: 1-click status updates, interview date scheduler, phone/email contact.

🛡️ Admin Moderation Panel

  • ✓ Manage Candidates & Employers: Central user directory with status filters.
  • ✓ Job Post Moderation: Review pending vacancies; approve or reject listings.
  • ✓ Manage Applications: Platform-wide application audit trail.
  • ✓ Live Dashboard Statistics: Total drivers, active jobs, applications, and placement rate.
  • ✓ User Governance: 1-click ban/suspend or reactivate users with instant session blocking.

📱 Multi-Platform Architecture

  • ✓ 1. Web Application: High-performance responsive SPA deployed live on Vercel.
  • ✓ 2. Android Mobile Application: Standalone React Native Expo project in android-mvp/.
  • ✓ Mobile Bottom Navigation: 1-tap thumb navigation for rapid on-the-go driver access.
  • ✓ Offline-First & Auto-Sync: Cloud persistence via Supabase PostgreSQL.

3. Supabase Database Schema Design

Table Name Columns & Relations Purpose & Capabilities
public.profiles id (UUID PK), role, full_name, email, phone, city, state, status, created_at Unified user identity for drivers, employers, and superadmins with real-time status syncing.
public.driver_profiles id, user_id (FK), driver_category, license_number, license_type, years_experience, skills, expected_salary Commercial credentials, verified experience, license type, and equipment competencies.
public.companies id, user_id (FK), company_name, industry, location, verified, status Fleet operator records, trust badges, operating locations, and company descriptions.
public.jobs id, employer_id (FK), company_id (FK), title, category, salary_min, salary_max, vacancies, status Commercial vacancies with salary scales, shift types, and moderation approval flags.
public.applications id, job_id (FK), driver_id (FK), cover_message, status, applied_date, interview_date Full applicant tracking lifecycle linking drivers to jobs with interview schedules.
